# My Dashboard (v1.0)

Python과 Streamlit으로 만든 개인/업무용 할 일 관리(Todo) 대시보드입니다.
JSON 파일 기반으로 데이터를 저장하며, 앱을 종료했다가 다시 실행해도
할 일 목록·순서·테마 설정이 그대로 유지됩니다.

현재는 개인/로컬 사용을 기준으로 설계되어 있습니다 (인증, 데이터베이스,
사내 서버 배포는 이후 버전에서 검토합니다).

## ✨ 프로젝트 소개

- **Dashboard 탭**: 오늘의 작업 현황(진행률/완료 수), High Priority, Due Today 지표 카드와 최근 완료 항목을 한눈에 확인
- **Todo 탭**: 할 일 카드 목록 - 우선순위 시각화, 요청자/LOT/SLOT/요청일 표시, 수동 순서 조정(▲▼), 완료 처리, 복사, 상세 편집
- **Today 탭**: "오늘의 작업" 자동 추천 + 직접 추가/제외로 관리, 오늘 기준 진행률
- **Completed 탭**: 완료된 할 일 확인, 복원(Restore), 삭제
- **Dark / Light 테마**: 선택한 테마는 재실행 후에도 유지

## 🛠 설치 방법

1. Python 3.9 이상이 설치되어 있어야 합니다.
2. 프로젝트 폴더로 이동한 뒤, 필요한 패키지를 설치합니다.

```bash
cd my_dashboard
pip install -r requirements.txt
```

## 🚀 실행 방법

```bash
streamlit run app.py
```

실행 후 터미널에 표시되는 주소(기본값 `http://localhost:8501`)를 브라우저로 열면 됩니다.

첫 실행 시 `data/tasks.json`이 없으면 빈 목록으로 자동 생성됩니다 - 예시
구조는 `data/tasks.example.json`을 참고하세요.

## 📌 기능 설명

### Task 정보
할 일마다 다음 정보를 관리할 수 있습니다 (제목/우선순위 외에는 모두 선택 사항):

| 필드 | 설명 |
|---|---|
| Title | 할 일 제목 |
| Priority | High / Medium / Low |
| Requester | 요청자 (자유 텍스트) |
| LOT / SLOT | 자유 텍스트 |
| Request Date | 요청일 |
| Due Date | 마감일 |
| Memo | 상세 메모 |

값이 없는 선택 항목은 화면에 "-"로 채우지 않고 아예 표시하지 않습니다.

### Todo 탭 - 할 일 카드
카드 하나가 3단계 정보 밀도로 구성됩니다:
- **항상 보임**: 순서 이동(▲▼) · 우선순위(색 배지 + 왼쪽 강조선, 색+텍스트 병행) · 제목(길어도 줄바꿈, 잘리지 않음) · 마감일 D-day 배지 · **완료하기** 버튼
- **항상 보임(값 있을 때만)**: 요청자 · LOT · SLOT · 요청일 요약 줄
- **접이식 상세/편집**: 전체 필드 편집, **복사**(popover), **삭제**(2단계 확인)

완료 처리는 체크박스가 아니라 **완료하기 버튼**을 명시적으로 클릭하는 방식이며,
클릭 시 짧은 토스트 알림이 표시됩니다.

### 수동 순서 정렬
- Todo 목록은 우선순위가 아니라 **사용자가 지정한 순서(order)**대로 표시됩니다.
  우선순위는 배지로 "정보"만 보여줄 뿐, 자동으로 목록 순서를 바꾸지 않습니다.
- 각 항목의 ▲▼ 버튼으로 바로 위/아래 항목과 순서를 바꿀 수 있습니다.
- 맨 위/맨 아래 항목은 해당 방향 버튼이 비활성화됩니다.
- 완료된 할 일의 순서는 전혀 간섭받지 않으며, 순서는 앱을 껐다 켜도 유지됩니다.
- (v1.0에서는 안정성을 위해 마우스 드래그 앤 드롭 대신 버튼 방식을 사용합니다 -
  자세한 이유는 아래 "v1.1 이후 후보" 참고)

### Today 탭 - 오늘의 작업
- 앱을 새 날짜에 처음 열면, 아래 규칙으로 자동 추천됩니다:
  1. 마감이 지났거나 오늘 마감인 할 일은 **무조건 포함**
  2. 나머지는 점수(우선순위 + 마감 임박도 + 요청일 경과일수) 순으로 소프트 타깃(기본 5개)까지 채움
     - 1번만으로 이미 5개를 넘으면 강제로 자르지 않고 전부 포함
  3. 어제 이미 오늘의 작업에 있었고 아직 미완료인 항목은 **이월(carried over)**
- **오늘의 작업에서 빼기**를 눌러도 원본 할 일은 삭제되지 않고, 그날 하루만 목록에서 빠집니다.
  다음날에는 조건이 맞으면 다시 추천될 수 있습니다 (영구 차단이 아닙니다).
- Todo 탭의 할 일 중 오늘 목록에 없는 것을 아래 "➕ Todo에서 오늘의 작업으로 추가"에서 수동으로 추가할 수 있습니다.
- 오늘 완료한 항목은 흐리게 표시된 채로 하루 동안 목록에 남아 진행률 계산에 반영됩니다.
- **진행률 = 완료된 오늘의 작업 수 / 전체 오늘의 작업 수** (예: 6/10 = 60%). Dashboard의 메인
  진행률 지표도 이 기준입니다. 전체 할 일 기준 완료율은 Dashboard 캡션에 보조 정보로 표시됩니다.

### Completed 탭
- 완료된 할 일과 완료 시각 표시
- Restore 버튼: 다시 Todo/Today 목록에 활성 상태로 복귀
- Delete 버튼: 완전 삭제

### 복사 기능
카드의 "📋 상세 / 편집"을 펼치면 **📋 복사** 버튼이 있습니다. 클릭하면 아래
형식의 텍스트가 `st.code` 블록(마우스를 올리면 복사 아이콘 표시)으로 나타나
이메일/메신저 등에 바로 붙여넣기 좋습니다. 값이 없는 선택 항목은 제외됩니다.

```
Title: ...
Requester: ...
LOT: ...
SLOT: ...
Request Date: ...
Due Date: ...
Priority: ...
Memo: ...
```

### 테마
- 사이드바에서 Light / Dark 모드 선택
- 선택한 테마는 `data/settings.json`에 저장되어 재실행 후에도 유지

## 🗂 데이터와 Git

`data/tasks.json`(실제 할 일)과 `data/today_list.json`(오늘의 작업 참조
정보)에는 개인/업무 데이터가 들어있어 `.gitignore`에 등록되어 있고, 저장소에는
올라가지 않습니다. 대신 안전한 예시 구조인 `data/tasks.example.json`만
커밋되어 있습니다.

`today_list.json`은 실제 할 일 정보를 복제하지 않고 `task_id`와 "오늘 목록
에서의 상태"(자동추천/직접추가/이월, 제외 여부)만 저장합니다 - 할 일의 실제
정보(제목, 완료 여부 등)는 항상 `tasks.json` 하나에만 존재합니다.

## 🔮 v1.1 이후 후보 (v1.0에서 의도적으로 제외)

  방식을 사용합니다.

- LOT/SLOT 입력 형식 검증
- 캘린더 뷰, 카테고리 분류, 반복 작업, 알림
- Excel 내보내기/가져오기, Google Calendar 연동
- 로그인(다중 사용자), 클라우드 동기화, 서버 배포
